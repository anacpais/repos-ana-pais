Formato da resposta

{
  "versao_dataset": "workshop-v1",
  "dados": [ ... ],
  "pagina": 1,
  "tamanho": 100,
  "total_registros": 1001,
  "total_paginas": 11,
  "proxima_pagina": "/vendas?pagina=2&tamanho=100"
}

A lista de registros está em dados. O campo proxima_pagina é um caminho relativo; concatene com o host. Quando terminar, ele será null.

Regras para o exercício

Cada registro de venda representa um item de pedido. A chave de negócio é (id_venda, numero_item). O desconto é o valor monetário total do item, em reais. Receita líquida = quantidade × preço unitário − desconto.

A base contém uma duplicata exata, um produto inexistente em uma venda e categorias com espaços e capitalização diferentes. Há também vendas canceladas. Preserve o conteúdo original na Bronze e trate as regras nas camadas seguintes.

Erros de parâmetros retornam HTTP 400 em JSON; rotas inexistentes retornam 404. Este é um servidor didático para dados fictícios, sem operações de escrita ou persistência de alterações.
